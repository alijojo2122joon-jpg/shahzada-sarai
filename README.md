# سامانه معاملات سرای شهزاده کابل
**Shahzada Sarai Trading Platform** — نسخه ۰.۲

سامانه رسمی ثبت پیشنهاد خرید و فروش ارز، طلا و نقره میان اعضای تأییدشده، همراه با انتشار نرخ رسمی بازار.
پرداخت و تحویل خارج از سامانه و مستقیماً میان طرفین انجام می‌شود.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/alijojo2122joon-jpg/shahzada-sarai)

## اجرا
نیازمند Node.js 22.5 یا جدیدتر. بدون وابستگی خارجی.
```bash
npm start            # http://localhost:3000
npm test             # ۴۴ آزمون: معامله، عضویت، امنیت
npm run loadtest     # آزمون حجم: ۲۰۰ هزار عضو، ۱۰۰ هزار سفارش، ۳۰۰ هزار معامله
npm run build:demo   # نسخه آزمایشی تک‌فایلی (dist/index.html)
```

## راه‌اندازی رسمی (تنظیمات Render ← Environment)
| متغیر | توضیح |
|---|---|
| `SEED=0` | بدون داده آزمایشی. **برای راه‌اندازی رسمی الزامی است.** |
| `ADMIN_PHONE` | شماره تماس مدیر اصلی |
| `ADMIN_PASSWORD` | رمز مدیر اصلی (حداقل ۱۰ حرف) |
| `ADMIN_PATH` | آدرس مخفی پنل مدیریت (پیش‌فرض `sh-panel-7319`) |
| `SECURE_COOKIE=1` | فعال پشت HTTPS |
| `DB_PATH` | مسیر پایگاه داده روی دیسک دائمی |

برای نگهداری دائمی داده، پلن دارای **دیسک دائمی** لازم است. در پلن رایگان داده‌ها با هر راه‌اندازی مجدد پاک می‌شود.

## امنیت
- نشست مدیر از نشست عمومی جداست؛ عملیات مدیریتی فقط از پنل مخفی ممکن است.
- تأیید دومرحله‌ای (Google Authenticator) برای مدیر؛ پایان خودکار نشست مدیر پس از ۳۰ دقیقه عدم فعالیت.
- ثبت نرخ رسمی، تغییر نقش، تغییر دارایی و اطلاعیه عمومی نیازمند وارد کردن مجدد رمز مدیر است.
- تغییر نرخ بیش از ۱۵٪ نیازمند تأیید جداگانه؛ فروش کمتر از خرید و فاصله بیش از ۱۰٪ پذیرفته نمی‌شود.
- قفل حساب پس از ۵ تلاش ناموفق؛ محدودیت تعداد درخواست برای هر IP و هر کاربر.
- رمزها با scrypt؛ کوکی HttpOnly؛ سیاست امنیت محتوا (CSP)، HSTS و مسدودسازی درخواست بین‌دامنه‌ای.
- سابقه عملیات به‌صورت زنجیره هش و جدول غیرقابل‌حذف در پایگاه داده.
- اولین ثبت‌نام‌کننده هرگز مدیر نمی‌شود؛ مدیر فقط از طریق متغیرهای محیطی ایجاد می‌شود.

## ظرفیت
- هر نوع داده در جدول جداگانه با ایندکس روی همه فیلدهای جستجو؛ همه فهرست‌ها محدود و صفحه‌بندی‌شده.
- نتیجه آزمون حجم (۲۰۰٬۰۰۰ عضو، ۱۰۰٬۰۰۰ سفارش، ۳۰۰٬۰۰۰ معامله): نمای بازار و عضو حدود ۲ میلی‌ثانیه، ثبت سفارش ۰٫۲ میلی‌ثانیه، ورود ۰٫۰۲ میلی‌ثانیه.
- به‌روزرسانی زنده هدفمند (فقط کاربران مرتبط) و تجمیع رویدادهای بازار.
- ساختار داده مستقیماً قابل انتقال به PostgreSQL برای چند سرور هم‌زمان.

## ساختار
```
shared/engine.js   قواعد کسب‌وکار (مشترک سرور و نسخه آزمایشی)
sqlstore.js        ذخیره‌سازی SQLite با ایندکس
server.js          سرور، API، نشست‌ها، امنیت، رویدادهای زنده
public/            رابط کاربری (راست‌به‌چپ)
scripts/           آزمون‌ها و ساخت نسخه آزمایشی
```
