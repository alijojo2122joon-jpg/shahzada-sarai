# بازار معاملات سرای شهزاده کابل
**Shahzada Sarai Digital Trading Platform** — نسخه ۰.۱

بازار دیجیتال برای صرافان، زرگران و تاجران سرای شهزاده: هر عضو سفارش خرید یا فروش ثبت می‌کند، دیگران درخواست می‌فرستند، صاحب سفارش کامل یا جزئی تأیید می‌کند و ارتباط مستقیم برقرار می‌شود.

> این نسخه فقط بستر معرفی پیشنهاد، ثبت درخواست و ارتباط خریدار و فروشنده است. انتقال پول، نگهداری دارایی و تسویه در سایت انجام نمی‌شود.

## اجرا

نیازمند **Node.js 22.5 یا جدیدتر**. هیچ پکیج خارجی لازم نیست (پایگاه داده SQLite داخل خود Node است).

```bash
npm start          # http://localhost:3000
npm test           # تست کامل جریان معاملات (۲۶ مورد)
npm run build:demo # ساخت dist/index.html — نسخه نمایشی تک‌فایلی که بدون سرور در مرورگر اجرا می‌شود
```

متغیرهای محیطی: `PORT`، `DB_PATH` (پیش‌فرض `data/sarai.db`)، `SEED=0` برای شروع بدون اطلاعات نمونه (اولین ثبت‌نام‌کننده مدیر می‌شود)، `SECURE_COOKIE=1` پشت HTTPS.

## امکانات نسخه ۰.۱
- **عضویت:** نام، شماره تماس و واتس‌اپ، نام صرافی، نوع فعالیت؛ تأیید یا مسدودسازی توسط مدیر؛ نشان «تأییدشده»؛ ویرایش پروفایل و رمز.
- **بازار:** سفارش خرید و فروش برای ارزها، طلا، نقره و هر دارایی که مدیر اضافه کند؛ واحد مقدار و قیمت دلخواه؛ محاسبه خودکار ارزش؛ مدت اعتبار؛ حداقل مقدار هر درخواست؛ فیلتر و مرتب‌سازی؛ خلاصه بهترین نرخ خرید و فروش هر دارایی؛ مقایسه پیشنهادهای رقیب.
- **درخواست و تأیید:** چند خریدار با مقادیر متفاوت؛ تأیید کامل یا جزئی؛ رد؛ پس‌گرفتن؛ نمایش مقدار باقی‌مانده. **مجموع مقادیر تأییدشده هرگز از مقدار سفارش بیشتر نمی‌شود** (عملیات سرور پشت‌سرهم اجرا می‌شود). لغو معامله، مقدار را به سفارش برمی‌گرداند. معامله فقط با تأیید هر دو طرف نهایی می‌شود.
- **ارتباط:** اطلاعات تماس بعد از تأیید درخواست (طبق تنظیم حریم خصوصی هر عضو)، لینک واتس‌اپ، گفتگوی داخل هر معامله، اعلان‌ها، به‌روزرسانی زنده (Server-Sent Events).
- **داشبورد:** سفارش‌های خرید و فروش، درخواست‌های دریافتی و ارسالی، در حال انجام، تکمیل‌شده، لغوشده، مقدار باقی‌مانده، تاریخچه، اعلان‌ها.
- **نرخ‌های بازار:** نرخ خرید و فروش عمومی (جدا از نرخ اعضا)، تغییرات و نمودار.
- **پنل مدیر:** کاربران و نقش‌ها، سفارش‌ها، معاملات، دارایی‌ها، نرخ‌ها، گزارش‌های روزانه/هفتگی/ماهانه، گزارش تخلفات، اعلان عمومی، تاریخچه فعالیت‌ها.
- **امنیت:** رمز با scrypt، نشست HttpOnly، محدودیت تلاش ورود، جلوگیری از درخواست‌های بین‌دامنه‌ای، CSP، جلوگیری از سفارش تکراری، تاریخچه رویدادها به‌صورت زنجیره هش و جدول غیرقابل‌ویرایش در پایگاه داده.

## ساختار
```
shared/engine.js   منطق کامل معاملات (مشترک بین سرور و نسخه نمایشی)
server.js          سرور HTTP + API + SQLite + رویدادهای زنده
public/            رابط کاربری راست‌به‌چپ (index.html, styles.css, app.js)
scripts/test.js    تست کامل جریان معاملات
scripts/build-standalone.js  ساخت نسخه نمایشی تک‌فایلی
```

## گام‌های بعدی پیشنهادی
تأیید شماره با پیامک (OTP)، اتصال واتس‌اپ و تلگرام برای اعلان، زبان انگلیسی، دریافت خودکار نرخ جهانی، انتقال ذخیره‌سازی به PostgreSQL برای حجم بالا، و استقرار روی سرور ابری با HTTPS.
